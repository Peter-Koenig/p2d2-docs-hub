# Release v0.1.0

## Überblick

- **Version**: v0.1.0
- **Veröffentlichungsdatum**: 21.11.2025
- **Status**: MVP Release

## Features

- Kern-Middleware-Architektur
- Basis-GDI mit OpenLayers
- PostgreSQL/PostGIS Integration
- OSM-Daten-Synchronisation

## Technische Komponenten

- **Frontend**: AstroJS
- **Backend**: TypeScript
- **Kartographie**: OpenLayers
- **Datenbank**: PostgreSQL/PostGIS

## Installation

```bash
# Beispiel-Installationsbefehl
npm install p2d2@0.1.0
```
