## Acerca de p2d2

p2d2 (Public-Public Data-DNA) es una plataforma innovadora para la gestión y visualización de datos geoespaciales públicos.

### Características Principales

- **Editor de Features** - Creación y edición de datos geoespaciales
- **Infraestructura de Datos Geoespaciales (GDI)** - Servicios WMS/WMTS
- **Arquitectura Modular** - Sistema escalable y extensible
- **Open Source** - Filosofía de código abierto
