# Release v0.1.0

## Overview

- **Version**: v0.1.0
- **Release Date**: 2025-11-21
- **Status**: MVP Release

## Features

- Core middleware architecture
- Basic SDI with OpenLayers
- PostgreSQL/PostGIS integration
- OSM data synchronization

## Technical Components

- **Frontend**: AstroJS
- **Backend**: TypeScript
- **Mapping**: OpenLayers
- **Database**: PostgreSQL/PostGIS

## Installation

```bash
# Example installation command
npm install p2d2@0.1.0
```

## Known Limitations

- Limited functionality
- Beta status
- Documentation in progress
