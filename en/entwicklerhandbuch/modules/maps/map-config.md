# Map Config

> **Status:** 🚧 Documentation in progress

## Overview

The map configuration defines the behavior of the map component in p2d2. It includes layer settings, projections, zoom levels, and default viewports.

## Functionality

- OpenLayers map configuration
- Layer definitions and ordering
- Projection settings
- Zoom and viewport configuration
- Interaction options
