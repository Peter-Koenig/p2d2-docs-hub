# p2d2 Dokumentation

Dokumentation für das p2d2-Projekt (Public-Public Data-DNA).

## Installation

```
npm install
```

## Development

```
npm run docs:dev
```

Öffnet Dev-Server auf http://localhost:5173

## Build

```
npm run docs:build
```

Erstellt statische Seiten in `.vitepress/dist/`

## Deployment

```
npm run docs:preview
```

Preview des Production-Builds.
