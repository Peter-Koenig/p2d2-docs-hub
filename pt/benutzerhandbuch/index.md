# Manual do Usuário

Bem-vindo ao Manual do Usuário do p2d2. Aqui você aprenderá como usar a aplicação, coletar dados geoespaciais e contribuir para a garantia de qualidade.

## Visão Geral

p2d2 é uma aplicação web que sincroniza dados abertos e gratuitos dos cidadãos com dados abertos de nossas administrações.

Começamos com dados geoespaciais, pois são de alto uso prático _e_ ilustrativos. A aplicação permite que os cidadãos verifiquem, corrijam e complementem os dados abertos da administração antes que sejam transferidos para plataformas públicas como OpenStreetMap ou WikiData, onde todos podemos usá-los e relacioná-los com outros dados.

## Público-Alvo

Este manual destina-se a:

- **Cidadãos** que desejam coletar e melhorar dados geoespaciais
- **Membros da comunidade** que garantem a qualidade dos dados
- **Funcionários administrativos** que revisam alterações de dados
