## Sobre p2d2

p2d2 (Public-Public Data-DNA) é uma plataforma inovadora para gestão e visualização de dados geoespaciais públicos.

### Recursos Principais

- **Editor de Features** - Criação e edição de dados geoespaciais
- **Infraestrutura de Dados Geoespaciais (GDI)** - Serviços WMS/WMTS
- **Arquitetura Modular** - Sistema escalável e extensível
- **Open Source** - Filosofia de código aberto
